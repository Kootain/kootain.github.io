Introduction

TypeScript 进化论：从 Python/Go 到全栈架构师

写给后端开发者的 TypeScript 转型指南

本书的核心设计理念是“关联映射学习法”——不从零教你写 if/else，而是将你脑海中已有的 Python/Go 概念直接映射到 TypeScript 的最佳实践中。

目标读者

  • 核心背景：资深 Python/Golang 开发者，熟悉后端架构、并发模型及类型系统。
  • 痛点：对 JavaScript 的认知停留在 jQuery/ES5 时代；对前端工程化、复杂的 TS 类型体操感到陌生。
  • 目标：掌握现代 TypeScript 全栈开发（Node.js 后端 + React 前端），理解 TS 类型系统的高级用法，能编写工业级代码。

核心原则

  • 拒绝废话：默认读者懂编程基础。
  • 对比教学：每个核心概念包含 [思维映射] 模块，对比 Python/Go 的实现方式。
  • 类型优先：从第一行代码开始就是 TypeScript。
