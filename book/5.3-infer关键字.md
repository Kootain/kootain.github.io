# 5.3 infer 关键字：类型提取器

`infer` 关键字只能在条件类型的 `extends` 子句中使用。它声明了一个 **待推断的类型变量**。

可以把它理解为正则表达式中的 **捕获组 (Capture Group)**。

## 1. 获取函数返回类型

TS 内置的 `ReturnType<T>` 是怎么实现的？

```typescript
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : any;
```

**解析**：
*   检查 `T` 是否是一个函数？
*   如果是，把它的返回值类型“捕获”并命名为 `R`。
*   返回 `R`。
*   否则返回 `any`。

**实战**：

```typescript
function getUser() {
    return { id: 1, name: "Alice", roles: ["admin"] };
}

// 自动提取 getUser 的返回类型
// UserType = { id: number; name: string; roles: string[] }
type UserType = ReturnType<typeof getUser>;
```

## 2. 获取 Promise 内部类型

后端开发常遇到：函数返回 `Promise<User>`，但我想要 `User` 类型。

```typescript
type Unpacked<T> = T extends Promise<infer U> ? U : T;

type AsyncResult = Promise<string>;
type Result = Unpacked<AsyncResult>; // string
```

## 3. 为什么这比 Python/Go 强？

*   **Python**: 运行时反射 (`inspect` 模块) 很强，但静态类型检查阶段很难做到这么灵活的提取。
*   **Golang**: 完全没有这种能力。你必须定义明确的 Struct。

`infer` 让我们能够从现有的代码（库、第三方模块）中“偷”出类型，而不需要重新定义一遍。
