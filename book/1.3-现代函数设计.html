1.3 现代函数设计

1.3 现代函数设计：箭头函数与解构

函数是所有编程语言的一等公民。TypeScript 引入了许多语法糖，让函数定义比 Python 更简洁，比 Go 更灵活。

1. 箭头函数 (Arrow Functions)

箭头函数 () => {} 不仅仅是 function 关键字的简写，它修正了 this 的指向问题。

[思维映射] this vs self vs Receivers

  • Python: 方法第一个参数显式写 self。
  • Go: 方法接收者显式写 (s *Service)。
  • JS (传统): this 是动态绑定的，取决于调用者（非常容易出错）。
  • TS (箭头函数): this 是 词法作用域 (Lexical Scoping) 绑定的。即：它捕获定义时的上下文，就像 Python 的闭包。

TypeScript:

class Handler {
    data = "Secret";

    // 使用箭头函数，自动绑定当前实例
    process = () => {
        console.log(this.data); 
    }
}
// 对比传统写法，不需要 .bind(this)

2. 默认参数与解构 (Destructuring)

Python **kwargs 的 TS 实现

Python 中我们常用 def func(**kwargs) 来处理复杂参数。TS 中使用 对象解构 来实现更强类型的“命名参数”。

Python:

def create_user(name, age=18, is_admin=False):
    pass

create_user(name="Alice", is_admin=True)

TypeScript (推荐写法):

interface UserOptions {
    name: string;
    age?: number;     // ? 表示可选
    isAdmin?: boolean;
}

// 在参数位置直接解构，并设置默认值
function createUser({ name, age = 18, isAdmin = false }: UserOptions) {
    console.log(name, age, isAdmin);
}

// 调用时必须传对象，类似 Python 的关键字参数
createUser({ name: "Alice", isAdmin: true });

Go 开发者注意：这比 Go 的 Functional Options 模式要简洁得多！

3. 函数重载 (Overloading)

Go 不支持重载，Python 也不支持（但在 Type Hints 中可以使用 @overload）。 TS 支持函数重载，但实现比较特殊：只有签名，没有多重实现。

// 重载签名 (Overload Signatures) - 给调用者看
function makeDate(timestamp: number): Date;
function makeDate(m: number, d: number, y: number): Date;

// 实现签名 (Implementation Signature) - 必须兼容上面所有情况
function makeDate(mOrTimestamp: number, d?: number, y?: number): Date {
    if (d !== undefined && y !== undefined) {
        return new Date(y, mOrTimestamp, d);
    } else {
        return new Date(mOrTimestamp);
    }
}

4. 总结

  • 能用箭头函数就用箭头函数。
  • 参数多于 2 个时，优先使用对象解构模式（模拟命名参数）。
  • 利用类型系统（Interface）来约束参数结构，比 Python 的 **kwargs 安全得多。
