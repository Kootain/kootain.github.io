11.1 构建工具链

11.1 构建工具链：天下武功，唯快不破

曾几何时，配置 Webpack 是前端工程师的噩梦。但现在，时代变了。

1. 为什么 JS 需要构建？

  • Python/Go: 源码 -> 解释器/编译器 -> 运行。
  • Legacy JS: 浏览器不支持新语法 (ES6+), 不支持模块化, 需要压缩体积。

2. Esbuild: Go 语言的降维打击

Webpack 是用 JS 写的，构建大型项目需要几分钟。 Esbuild 是用 Go 写的，构建速度比 Webpack 快 10-100 倍。

它证明了：系统级语言（Go/Rust）是重写前端工具链的最佳选择。

3. Vite: 下一代前端构建工具

Vite (法语“快”) 基于 Esbuild。

  • 开发环境: 利用浏览器原生的 ESM 支持，几乎秒启动（No-bundle）。
  • 生产环境: 使用 Rollup 打包，确保兼容性。

对于后端开发者，Vite 就像 go run 一样简单。你不需要去写几百行的 webpack.config.js，通常开箱即用。

4. 建议

  • 新项目: 无脑选 Vite。
  • 老项目: 尝试迁移到 Vite 或 Rspack (Rust 版 Webpack)。
