# 11.2 单元测试：Vitest

在很长一段时间里，Jest 是 TS 测试的标准。但 Jest 比较慢，且配置 TS 支持比较麻烦。

## 1. Vitest: 极速测试框架

Vitest 是 Vite 的原生测试框架。

*   **配置**: 复用 `vite.config.ts`。
*   **速度**: 基于 Worker 线程并发运行，使用 Esbuild 编译 TS。
*   **API**: 几乎完全兼容 Jest。

## 2. 对比 Golang Testing

**Golang (`testing`):**
```go
func TestAdd(t *testing.T) {
    got := Add(1, 2)
    if got != 3 {
        t.Errorf("expected 3, got %d", got)
    }
}
```

**TypeScript (Vitest):**
```typescript
import { expect, test } from 'vitest';
import { add } from './math';

test('add', () => {
    expect(add(1, 2)).toBe(3);
});
```

Vitest 提供了类似 Python `pytest` 的丰富断言库 (`expect(...)`)，比 Go 原生的 `if !=` 更加表达性强。

## 3. 测试替身 (Mocks)

Vitest 内置了强大的 Mock 能力，用于隔离数据库或外部 API。

```typescript
import { vi, test, expect } from 'vitest';
import db from './db';

// Mock 掉 db 模块
vi.mock('./db', () => ({
    default: {
        getUser: vi.fn().mockReturnValue({ id: 1, name: "Test" }),
    },
}));

test('mocking', async () => {
    const user = await db.getUser(1);
    expect(user.name).toBe("Test");
});
```

这比 Go 的 `gomock` 或 `testify/mock` 写起来要轻松灵活得多（得益于 JS 的动态特性）。
