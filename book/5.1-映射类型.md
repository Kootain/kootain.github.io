# 5.1 映射类型：编译时的 For 循环

在 Python/Go 中，我们习惯遍历数组或 Map。在 TypeScript 中，我们可以遍历 **类型** 的属性，并基于它们生成新的类型。这被称为 **映射类型 (Mapped Types)**。

## 1. 语法结构

语法：`[K in keyof T]: NewType`

*   `K`: 循环变量 (Key)
*   `keyof T`: 遍历范围 (T 的所有属性名)
*   `NewType`: 新属性的类型

## 2. 实战：Partial 与 Readonly 的实现原理

TS 内置的 `Partial<T>`（将所有属性变可选）和 `Readonly<T>`（将所有属性变只读）就是通过映射类型实现的。

**定义 Partial:**
```typescript
type MyPartial<T> = {
    [K in keyof T]?: T[K]; 
    // ?: 表示加上 optional 修饰符
    // T[K] 表示保持原来的类型
};
```

**定义 Readonly:**
```typescript
type MyReadonly<T> = {
    readonly [K in keyof T]: T[K];
};
```

**Go 开发者震惊时刻:**
在 Go 中，如果你想定义一个所有字段都是指针（可选）的结构体，你必须手写一个新的 Struct，或者用代码生成器。
在 TS 中，这只是一个简单的类型运算：

```typescript
interface User {
    id: number;
    name: string;
}

// 自动生成: { id?: number; name?: string }
type UpdateUserDTO = Partial<User>;
```

## 3. 键名重映射 (Key Remapping)

TS 4.1+ 甚至允许你修改 Key 的名字。

```typescript
type Getters<T> = {
    [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K]
};

interface Person {
    name: string;
    age: number;
}

// 自动生成:
// {
//    getName: () => string;
//    getAge: () => number;
// }
type PersonGetters = Getters<Person>;
```
这完全就是 **编译时的反射 (Compile-time Reflection)**。
