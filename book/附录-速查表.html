1. Golang to TypeScript

Golang TypeScript 备注
var x int / x := 0 let x: number = 0 TS 推荐用 const
struct interface (或 type) TS 接口更灵活，运行时擦除
func (s *S) Method() class S { method() {} } TS 也可以用闭包模拟
interface (Method Set) interface (Shape) TS 是鸭子类型，不需要显式 implement
go func() Promise (非阻塞) TS 是单线程并发，无并行
chan Observable (RxJS) 或 AsyncGenerator 原生 TS 无 Channel，需引入库
defer try...finally React 中对应 useEffect return
json:"name" (Tag) Decorator (NestJS) 或 Zod/Pydantic TS 无原生 Tag，靠库实现
map[string]int Record<string, number> 或 Map<string, number>
[]int number[] 或 Array<number>
interface{} / any unknown (安全) / any (不安全) 优先使用 unknown
make([]int, 0, 10) [] JS 数组自动扩容，无 cap 概念
package Module (ESM) 文件即模块
public/private (大小写) public/private 关键字 TS 还有 #private (运行时私有)

Python TypeScript 备注
list Array<T>
dict Record<K, V> 或 Map
set Set<T>
None null / undefined TS 分得更细，建议统一用 undefined
def func(a, b=1) function func(a, b=1)
*args ...args (Rest Parameters)
**kwargs Object Destructuring function({ a, b }: Opts)
lambda x: x+1 x => x + 1 箭头函数
List[int] number[]
Union[A, B] `A B`
Optional[T] `T undefined` 或 ?: (可选属性)
__init__ constructor
asyncio.run() Top-level await Node 14+ 支持顶层 await
pip install npm install
venv node_modules 局部安装是默认行为

3. 常用工具类型映射

需求 TS 工具类型 解释
所有属性变可选 Partial<T> Patch API 常用
所有属性变必填 Required<T>
所有属性变只读 Readonly<T> 类似 Go 只读 View
提取部分属性 `Pick<T, 'id' 'name'>` 类似 SQL SELECT
排除部分属性 Omit<T, 'password'> 返回给前端时脱敏
排除 null/undefined NonNullable<T>
获取函数返回值 ReturnType<T> 极其常用
