4.1 泛型基础

4.1 泛型基础：不仅仅是模板

泛型是构建可复用组件的基石。它允许我们在定义函数、接口或类时，不预先指定具体的类型，而在使用时再指定。

1. 语法对照表

语言 语法示例 说明
TypeScript function identity<T>(arg: T): T 使用尖括号 <T>
Golang (1.18+) func Identity[T any](arg T) T 使用方括号 [T any]
Python def identity(arg: T) -> T 需预先定义 T = TypeVar("T")

2. 泛型函数与接口

TypeScript:

// 泛型接口
interface Box<T> {
    contents: T;
}

// 泛型函数
function unbox<T>(box: Box<T>): T {
    return box.contents;
}

const stringBox: Box<string> = { contents: "hello" };
const r = unbox(stringBox); // TS 自动推断 T 为 string

对比 Golang:

type Box[T any] struct {
    Contents T
}

func Unbox[T any](b Box[T]) T {
    return b.Contents
}

两者惊人地相似。但 TS 的类型推断（Inference）通常比 Go 更强，很多时候不需要显式写 <string>。

3. 泛型类

class Queue<T> {
    private data: T[] = [];
    push(item: T) { this.data.push(item); }
    pop(): T | undefined { return this.data.shift(); }
}

const q = new Queue<number>(); // 只能存数字

4. 默认泛型参数

TS 允许给泛型提供默认值，这在 React 组件或复杂工具类型中很常见。

// 如果不传 T，默认为 string
interface Response<T = string> {
    data: T;
    status: number;
}

const r1: Response = { data: "ok", status: 200 }; // T is string
const r2: Response<number> = { data: 123, status: 200 }; // T is number

这是 Python 和 Go 目前都不支持的特性。
