# 5.2 条件类型：编译时的 If/Else

如果说映射类型是 `for` 循环，那么条件类型 (Conditional Types) 就是 `if-else`。

## 1. 语法结构

语法：`T extends U ? X : Y`

这看起来像三元运算符，但它是作用于 **类型** 的。

> 如果类型 T 可以赋值给类型 U，则结果是 X 类型，否则是 Y 类型。

## 2. 分布式条件类型 (Distributive Conditional Types)

这是 TS 最烧脑但也最强大的特性：**当 T 是联合类型时，条件类型会自动分发。**

```typescript
// 定义一个移除类型的工具
type MyExclude<T, U> = T extends U ? never : T;

// 用法
type Result = MyExclude<"a" | "b" | "c", "a">; // 结果是 "b" | "c"

// 推导过程：
// ("a" extends "a" ? never : "a") |
// ("b" extends "a" ? never : "b") |
// ("c" extends "a" ? never : "c")
// => never | "b" | "c"
// => "b" | "c"
```

## 3. 实战：DeepReadonly

Go 无法轻易实现“递归只读”。TS 可以通过条件类型 + 递归实现。

```typescript
type DeepReadonly<T> = {
    readonly [K in keyof T]: T[K] extends object 
        ? DeepReadonly<T[K]> // 如果是对象，递归调用
        : T[K];              // 否则保持原样
};

interface Complex {
    a: {
        b: {
            c: number;
        }
    }
}

type ReadonlyComplex = DeepReadonly<Complex>;
// ReadonlyComplex.a.b.c = 1; // ❌ Error
```

## 4. 总结

条件类型赋予了 TS **图灵完备** 的能力。你可以用它在编译阶段写出复杂的逻辑判断。
对于业务开发，重点掌握 `Exclude`, `Extract`, `NonNullable` 这几个内置工具即可。
