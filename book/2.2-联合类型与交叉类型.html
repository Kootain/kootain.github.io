2.2 联合类型与交叉类型

2.2 联合类型与交叉类型 (Union & Intersection)

这是 TypeScript 相比 Golang 最具杀伤力的特性之一，也是 Python 3.10+ 开始大力补全的功能。

1. 联合类型 (Union Types) |

场景：一个变量可能是字符串，也可能是数字。

[思维映射]

  • Python: Union[str, int] 或 str | int (3.10+)。
  • Golang: 痛苦。通常需要定义 interface{} 然后进行 Type Assertion (类型断言)，或者使用 Go 1.18+ 的泛型约束。
  • TypeScript: 原生支持 |。

TypeScript:

function padLeft(value: string, padding: string | number) {
    // 此时 padding 是 string | number
    // TS 会强制你处理两种情况（类型收窄 Type Narrowing）

    if (typeof padding === "number") {
        // 在这个 if 块里，TS 智能地知道 padding 是 number
        return " ".repeat(padding) + value;
    }
    // 这里 TS 知道 padding 只能是 string
    return padding + value;
}

对比 Golang 的痛苦写法:

func padLeft(value string, padding interface{}) {
    switch v := padding.(type) {
    case int:
        // ...
    case string:
        // ...
    }
}

TS 的优势在于：控制流分析 (Control Flow Analysis)。它能根据 if/switch 自动推断剩余代码的类型。

2. 交叉类型 (Intersection Types) &

场景：把两个对象合并成一个新对象（拥有两者的所有属性）。

[思维映射] 结构体组合

  • Golang: Struct Embedding (结构体嵌入)。
  • Python: 多重继承 (Multiple Inheritance)。
  • TypeScript: & 运算符。

TypeScript:

interface ErrorHandling {
    success: boolean;
    error?: string;
}

interface ArtData {
    artworks: string[];
}

// 组合成一个新类型 Response
type ArtResponse = ArtData & ErrorHandling;

const resp: ArtResponse = {
    artworks: ["Mona Lisa"],
    success: true
};

Golang 等效:

type ArtResponse struct {
    ArtData
    ErrorHandling
}

3. 总结

  • | (Union) 是 OR 逻辑：是 A 或者 B。这是处理“多态”参数的神器。
  • & (Intersection) 是 AND 逻辑：既是 A 又是 B。这是组合对象的神器。

学会使用 | 替代 any，是迈向 TS 高级开发者的第一步。
