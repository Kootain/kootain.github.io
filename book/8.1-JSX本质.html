8.1 JSX 本质

8.1 JSX 本质：UI 即函数

别被 HTML 标签骗了。React 不是在写 HTML，而是在写 JS。

1. 公式：UI = f(State)

React 的核心哲学极其简单：视图是状态的函数。

// 纯函数
function UserCard(props: { name: string }) {
    return <h1>Hello, {props.name}</h1>;
}

当 props.name 变化时，React 再次调用这个函数，生成新的虚拟 DOM，对比差异，更新真实 DOM。

[思维映射]

  • Go/Python 模板: Jinja2 或 html/template 是字符串拼接。逻辑与视图分离。
  • React: 逻辑与视图 耦合 (Co-location)。JSX 只是函数调用的语法糖。
// JSX
<div id="app">Hello</div>

// 编译后的 JS
React.createElement("div", { id: "app" }, "Hello")

2. 组件化 (Composition)

后端习惯用继承 (Inheritance) 复用逻辑，React 提倡组合 (Composition)。

function Layout({ children }: { children: React.ReactNode }) {
    return (
        <div className="container">
            <Sidebar />
            <main>{children}</main>
        </div>
    );
}

这非常像 Go 的 Struct Embedding 或 Python 的 Decorator 模式。

3. 为什么 TS + React 是绝配？

因为 JSX 本质是 JS，所以 TS 可以对 JSX 进行类型检查！

interface Props {
    count: number; // 必填
    title?: string; // 可选
}

function Counter({ count, title }: Props) { ... }

// ✅
<Counter count={1} />

// ❌ Error: Property 'count' is missing
<Counter title="Hi" />

这种 模板层的类型安全 是传统模板引擎（Jinja2/Go Template）无法比拟的。
